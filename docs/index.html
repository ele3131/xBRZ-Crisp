xBRZ crisp

xBRZ smooths every corner it finds, so soft shading and textures melt into blobs. xBRZ crisp only rounds a corner when its two colors are clearly different. Outlines, text and sprites are smoothed as in xBRZ, and grass, foliage and stone keep the pixels the artists drew.

Drag the line to compare. All frames are Game Boy Advance screens at 6x, rendered with the RetroArch shader code. Integer (integer scaling) shows the original pixels. MMPX Adv (MMPX Advanced) is the libretro scalenx shader at 2x, enlarged 3x, and ScaleFX is the libretro scalefx-9x preset at 9x, scaled down to 6x by area averaging. xBRZ (latest) is the current libretro xbrz-freescale-multipass, which already includes improvements that came from xBRZ Crisp.

Presets

There is one preset, xbrz-crisp, with a minimum contrast of 24, a balance between xBRZ smoothness and the original pixels. To change it, set XBRZ_MINC in Quick Menu › Shaders › Shader Parameters and save the preset. The cost is the same as xbrz-freescale-multipass at any value. Good steps:

XBRZ_MINCLook
12xBRZ with light improvements: only the softest shading and textures keep their pixels.
16Textures and soft shading keep their pixels, while outlines, faces and text are smoothed as in xBRZ.
24 (default)Grass, foliage and textures keep most of their pixel detail, the closest to the original art, while outlines, faces and text are still smoothed. Some soft diagonals turn into steps.

Parameters

Every value can be changed live in Quick Menu › Shaders › Shader Parameters.

ParameterDefaultWhat it does
XBRZ_MINC24Minimum color contrast (x/255) for a corner to be rounded. 0 turns it off (the tolerance and steep thresholds below still apply).
XBRZ_DIAG100Maximum color distance (x/255) between the two colors a cut would join. Above it, the corner stays square. 0 turns it off.
XBRZ_TOL15Equal color tolerance. The reference C++ xBRZ uses 30.
XBRZ_STEEP3.2Steep and shallow line threshold. The reference C++ xBRZ uses 2.2, which turns 1-pixel steps into slopes; 3.2 keeps letters and 1-pixel details closer to the original.
XBRZ_DOM3.8Dominant direction threshold. The reference C++ xBRZ uses 3.6; 3.8 keeps small corners close to square instead of cutting them into long tips.

How it works

xBRZ decides corner by corner whether to cut a pixel's corner with a neighbor's color. xBRZ crisp keeps that decision and adds one check before drawing: if the pixel and the blend color are closer than the minimum contrast (YCbCr distance), the corner stays square. Edge detection is unchanged, so shapes are found exactly as before, and only the low-contrast blends are skipped.

Since 1.4 there is a second check: a cut joins the two neighbors on the corner's diagonal, and if those two colors differ by more than XBRZ_DIAG (100), the corner is a junction of different colors and stays square. Antialiasing ramps, where one of the two colors sits between the pixel and the other one, use a limit of 92, corners on shallow or steep lines are never blocked, and a blocked corner is still cut when the next corner along the same diagonal is cut, so lines are drawn to the end. Where stacked 1-pixel stripes end flush, as in health bars, the end corners stay square when their diagonal colors differ by more than 64, so every stripe ends the same way. The idea comes from cleanEdge by torcado.

The shader is based on the libretro xbrz-freescale-multipass port. A few details were aligned with the reference C++ xBRZ: blend color ties and the order of the four corners follow the original, the GLSL version takes the output scale from the image size instead of the texture size, and the output pass reads the image from the pass before xBRZ, so it also works after other shaders in a preset.

Install

  1. Copy the xbrz files into RetroArch's shader folder: shaders_slang/edge-smoothing/xbrz/ for Vulkan, glcore, D3D and Metal, or shaders_glsl/xbrz/ for the gl driver.
  2. In a game, open Quick Menu › Shaders › Load and pick xbrz-crisp.
  3. Save it with Quick Menu › Shaders › Save › Save Global Preset, or per game with Save Game Preset.
