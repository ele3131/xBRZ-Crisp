xBRZ crisp

xBRZ smooths every corner it finds, so soft shading and textures melt into blobs. xBRZ crisp only rounds a corner when its two colors are clearly different. Outlines, text and sprites are smoothed as in xBRZ, and grass, foliage and stone keep the pixels the artists drew.

Drag the line to compare. All frames are Game Boy Advance screens at 6x, rendered with the RetroArch shader code.

Presets

There is one preset, xbrz-crisp, with a minimum contrast of 24, which keeps the textures closest to the original art. To change it, set XBRZ_MINC in Quick Menu › Shaders › Shader Parameters and save the preset. The cost is the same as xbrz-freescale-multipass at any value. Good steps:

XBRZ_MINCLook
16Softer, closer to xBRZ. Textures stop melting, soft shadows and faces stay like xBRZ.
24 (default)More texture detail in grass and foliage, closer to the original art. Some soft diagonals turn into steps.
32Sharpest. Pale skin and soft shadows can start to look blocky.

Parameters

Every value can be changed live in Quick Menu › Shaders › Shader Parameters.

ParameterDefaultWhat it does
XBRZ_MINC24Minimum color contrast (x/255) for a corner to be rounded. 0 turns it off (the tolerance and steep thresholds below still apply).
XBRZ_MINC_RAMP0Width of a soft transition around the threshold, so corners shrink gradually instead of switching at once. 0 is a hard cut.
XBRZ_TOL15Equal color tolerance. Stock xBRZ uses 30.
XBRZ_STEEP3.0Steep and shallow line threshold. Stock xBRZ uses 2.2, which turns 1-pixel steps into slopes.
XBRZ_DOM3.6Dominant direction threshold.
XBRZ_LUMA1.0Weight of brightness against color in the comparisons.

How it works

xBRZ decides corner by corner whether to cut a pixel's corner with a neighbor's color. xBRZ crisp keeps that decision and adds one check before drawing: if the pixel and the blend color are closer than the minimum contrast (YCbCr distance), the corner stays square. Edge detection is unchanged, so shapes are found exactly as before, and only the low-contrast blends are skipped.

The shader is based on the libretro xbrz-freescale-multipass port. A few details were aligned with the reference C++ xBRZ: blend color ties and the order of the four corners follow the original, and the GLSL version takes the output scale from the image size instead of the texture size.

Install

  1. Copy the xbrz files into RetroArch's shader folder: shaders_slang/edge-smoothing/xbrz/ for Vulkan, glcore, D3D and Metal, or shaders_glsl/xbrz/ for the gl driver.
  2. In a game, open Quick Menu › Shaders › Load and pick xbrz-crisp.
  3. Save it with Quick Menu › Shaders › Save › Save Global Preset, or per game with Save Game Preset.
